# Git

## Git이란?
분산 버전 관리 시스템

## Git의 역할


## Git의 영역
1. Working Directory
2. Staging Area
3. Repository

## Git 명령어
git init  깃 관리 시작 (master가 관리하고 있다. )
git status  뭐를 관리하고 있는지 보고 싶을 때 (untracted: 관리를 안 하고 있다)
git add [what] ([what])  깃아 추가해줘 무언가/경로를 (랑 다른 것도)
git commit  버전을 남긴다
git commit -m "[메세지]"  깃아 메세지를 추가해서 버전을 남겨줘. 
git log  버전의 기록을 보기

git log --oneline  버전 기록을 한 줄로 예쁘게 보자
git log --oneline --graph  주가 만들었는지 예쁘게 보고 싶다. (다음 시간에..)
